# gun-game

このプロジェクトはPhaserJSで作られたツインスティックシューターゲームです。Vampire SurvivorsとBrotatoにインスパイアされた、ローグライクサバイバルゲームです。

## 🎮 ゲームの特徴

- **ツインスティック操作**: WASDで移動、マウスで照準
- **自動射撃システム**: マウスの方向に自動で弾を発射
- **Wave制の敵**: 時間経過で敵が強化
- **経験値システム**: 敵を倒すとXPオーブをドロップ
- **レベルアップ**: 3つのランダムアップグレードから選択
- **ステータス強化**: 攻撃速度、移動速度、ダメージなど

## 🕹️ 操作方法

- **WASD**: プレイヤーの移動
- **マウス**: 照準の操作（自動射撃）
- **レベルアップ時**: 3つのアップグレードから1つを選択

## 🚀 デプロイ

このゲームはVercelで静的ホスティングされています。

### ローカルで実行

```bash
# プロジェクトをクローン
git clone https://github.com/todo-hs/gun-game.git
cd gun-game

# ブラウザでindex.htmlを開く
open index.html
```

1. GitHubにリポジトリをプッシュ
2. Vercelでプロジェクトをインポート
3. フレームワーク設定: Other
4. ビルドコマンド: なし
5. 出力ディレクトリ: /

# 🕊️ カモメ、盗み食い。 〜観光客の食べ物を空から奪え。食べるほど重くなって、飛べなくなる〜

トップページ（`index.html`）で遊べるメインのゲームです。アニメ調（トゥーン描画）の海辺の観光地を、カモメになって飛び回る3Dゲーム（Three.js）。
ローカルなら `python3 -m http.server` を起動して `http://localhost:8000/` を開いてください（ES モジュールなのでファイル直開きでは動きません）。

## ルール
- 1回 **3分**。観光客や屋台から食べ物を盗んで **被害総額（円）** を稼ぐスコアアタック。結果で称号がもらえる
- 翼は **左右別々に羽ばたく**。左の翼（A）を羽ばたくと体が右に傾いて右に曲がる。スペースで両方。W/S で頭の上げ下げ、Shift で急降下。遅くなると失速する
- ポテト・ソフトクリーム・たこ焼きなど小さい物はその場で食べる。弁当・魚・特大バーガー・**本マグロ** は、くわえて灯台の巣まで運ぶ（体重が足りないと持てない）
- 食べるほど **重くなって羽ばたきが効かなくなる**。**5kg で破裂**
- 盗まれた人は怒って手ではたいてくる。魚市場の人は最初から警戒している
- 獲物をくわえていると **トンビ** が奪いに来る（「トンビに油揚げをさらわれる」）。逃げ切って巣に運ぶとボーナス
- **F でフン** を落とす。当たった人は持っている食べ物を落とす
- 建物に速くぶつかる・地面に突っ込むと気絶して、くわえた物を落とす。海に落ちたらスペース連打で飛び立つ
- ミッション9個（ポテトを盗む、トンビから逃げ切る、本マグロを持ち帰る など）は達成すると保存される

## 操作
A / D: 左 / 右の翼で羽ばたく（マウスなら左クリック / 右クリック） / スペース: 両方の翼 / W・S: 頭を下げる・上げる / Shift: 急降下 / F: フン / E: 鳴く / 矢印キー・マウス: カメラ / Esc: メニュー / M: 音
地上・水上では W で歩く、A/D で向きを変える、スペースで飛び立つ。

## ファイル構成（`gull/`、ES モジュール）
- `main.js` 起動・タイトル・入力・ループ・空と光 / `game.js` 飛び方の物理・盗み・巣・フン・トンビ・人間・カメラ
- `world.js` 海辺の町（遊歩道の屋台・砂浜・海の家・魚市場・桟橋・灯台） / `build.js` 当たり判定の箱・まとめ描画・看板 / `toon.js` トゥーン陰影と輪郭線
- `bird.js` カモメのモデル / `people.js` 人間とトンビ / `items.js` 食べ物 / `config.js` 数値・食べ物・ミッション・天の声・セーブ / `hud.js` 画面の文字と地図 / `audio.js` 効果音・風切り音

# 🐱 デブ猫、町内会長になる。 〜食べ歩いて太れ。でも隙間は通れない。100kgで破裂する。〜

前作。`fatcat/` で遊べます。アニメ調（トゥーン描画）の猫になって、猫目線の町を歩き回る3Dオープンワールド（Three.js）。
ローカルなら `python3 -m http.server` を起動して `http://localhost:8000/` を開いてください（ES モジュールなのでファイル直開きでは動きません）。

## 目的
町の3匹のボス猫を倒して、神社の「町内会長の座」に座ればエンディング。ボスは体重が近くないとパンチが効かない。
- **ミケ姐さん（12kg）**: 住宅街の屋上。物置→室外機→ベランダと跳んで登る。ジャンプ力が落ちるので **18kg を超えると登れない**
- **ブチ（25kg）**: 公園の砂場。とにかく太れ
- **クロ（40kg）**: 路地裏。入口の隙間は **8kg まで**。中の残飯で太って勝ったら、内側の重い扉を **35kg 以上で** 押し開けて出る

## 町
- 商店街: 魚屋（カウンターの魚を食べるとおやじがほうきで払う。30kg あればびくともしない）/ 焼き鳥屋（焼き台は熱い）/ パン屋 / コンビニ / 大通りのトラック（はねられたら失敗。60kg あればトラックが止まる）
- 住宅街・犬のいる家（鎖の範囲に入ると噛まれる。30kg あれば犬が降参）/ 公園（ベンチのおばあちゃんに鳴くとおやつ）/ 路地裏 / 神社
- ゴミ箱を猫パンチで倒すと中身が出る。カラスは食べ物を盗むので追い払う
- 町の猫に E で鳴くとヒントをくれる。猫缶バッジ 10 個が隠れている（車の下は 6kg まで、など）
- 失敗（詰まる・破裂・トラック）しても、家（段ボール）から再開。倒したボスと集めたバッジはそのまま。進行は自動で保存

## 操作
WASD: 移動 / Shift: ダッシュ（スタミナ制。太るほど早くバテる） / マウス or 矢印キー: 見回す / スペース: ジャンプ（長押しで高く） / クリック or J: 猫パンチ / F・右クリック・K: 吐いて痩せる / E: 鳴く（話しかける） / Esc: メニュー / M: 音

マウスがなくてもキーボードだけで遊べます。

## ファイル構成（`fatcat/`、ES モジュール）

- `town.js` 町の地形と建物（材質ごとにまとめて描画）・当たり判定・出現位置 / `toon.js` トゥーン陰影と輪郭線
