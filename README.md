# Twin-Stick Survivor Game

このプロジェクトはPhaserJSで作られたツインスティックシューターゲームです。Vampire SurvivorsとBrotatoにインスパイアされた、ローグライクサバイバルゲームです。

## 🎮 ゲームの特徴

- **ツインスティック操作**: WASDで移動、マウスで照準
- **自動射撃システム**: マウスの方向に自動で弾を発射
- **Wave制の敵**: 時間経過で敵が強化
- **経験値システム**: 敵を倒すとXPオーブをドロップ
- **レベルアップ**: 3つのランダムアップグレードから選択
- **ステータス強化**: 攻撃速度、移動速度、ダメージなど

## 🕹️ 操作方法

- **WASD**: プレイヤーの移動
- **マウス**: 照準の操作（自動射撃）
- **レベルアップ時**: 3つのアップグレードから1つを選択

## 🚀 デプロイ

このゲームはVercelで静的ホスティングされています。

### ローカルで実行

```bash
# プロジェクトをクローン
git clone https://github.com/todo-hs/gun-game.git
cd gun-game

# ブラウザでindex.htmlを開く
open index.html
```

### Vercelへのデプロイ

1. GitHubにリポジトリをプッシュ
2. Vercelでプロジェクトをインポート
3. フレームワーク設定: Other
4. ビルドコマンド: なし
5. 出力ディレクトリ: /

# 🐱 デブ猫ガンナー 〜太るほど強い。でも穴に詰まる。〜

`fatcat/` フォルダに入っている別ゲームです。デプロイ後は `/fatcat/` で遊べます（ローカルなら `python3 -m http.server` を起動して `http://localhost:8000/fatcat/` を開く）。

## ルール
- ネズミ・魚・犬を食べると **太る**。太るほど弾が強く、体重がそのまま体力になる
- でも太ると **穴や通路に入れない**。穴の中で太ると **詰まって** 3.5秒で死亡
- **SPACE / 右クリックで吐く** と痩せる。吐いた毛玉は攻撃になり、落ちると魚に戻る（半分の重さ）
- 自分よりデカい犬には噛まれ（体重が減る）、自分より小さい犬は丸のみできる

## ステージ
1. 食べると太る（チュートリアル）
2. 体重計ドア（14kg以上で開くドアのすぐ先に 7.3kg までのトンネル）
3. 掃除機がくる（強制スクロール＋トンネル内の罠の魚）
4. ボス: ブル太（倒したら猫用ドアを通るため痩せる）
5. 最終試験（全部入り）

## 操作
WASD/矢印: 移動 / マウス: 照準（自動射撃） / SPACE・右クリック: 吐く / R: 即リトライ / ESC: タイトル / M: 音のオンオフ

## ファイル構成
- `fatcat/levels.js` ステージのマップ（文字で編集できる）
- `fatcat/config.js` 体重と大きさ・速さ・攻撃力の式、敵のパラメータ、効果音
- `fatcat/GameScene.js` ゲーム本体 / `HudScene.js` 画面UI / `TitleScene.js` タイトル / `BootScene.js` スプライト描画
