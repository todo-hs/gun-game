# gun-game

このプロジェクトはPhaserJSで作られたツインスティックシューターゲームです。Vampire SurvivorsとBrotatoにインスパイアされた、ローグライクサバイバルゲームです。

## 🎮 ゲームの特徴

- **ツインスティック操作**: WASDで移動、マウスで照準
- **自動射撃システム**: マウスの方向に自動で弾を発射
- **Wave制の敵**: 時間経過で敵が強化
- **経験値システム**: 敵を倒すとXPオーブをドロップ
- **レベルアップ**: 3つのランダムアップグレードから選択
- **ステータス強化**: 攻撃速度、移動速度、ダメージなど

## 🕹️ 操作方法

- **WASD**: プレイヤーの移動
- **マウス**: 照準の操作（自動射撃）
- **レベルアップ時**: 3つのアップグレードから1つを選択

## 🚀 デプロイ

このゲームはVercelで静的ホスティングされています。

### ローカルで実行

```bash
# プロジェクトをクローン
git clone https://github.com/todo-hs/gun-game.git
cd gun-game

# ブラウザでindex.htmlを開く
open index.html
```

### Vercelへのデプロイ

1. GitHubにリポジトリをプッシュ
2. Vercelでプロジェクトをインポート
3. フレームワーク設定: Other
4. ビルドコマンド: なし
5. 出力ディレクトリ: /

# 🐱 デブ猫、詰まる。 〜太るほど強い。でも隙間に詰まる。100kgで破裂する。〜

トップページ（`index.html`）で遊べるメインのゲームです。実寸大のアパートを猫目線で動き回る3Dゲーム（Three.js + cannon-es 物理）。
ローカルなら `python3 -m http.server` を起動して `http://localhost:8000/` を開いてください（ES モジュールなのでファイル直開きでは動きません）。

## ルール
- 茶トラ猫になって、リビング・キッチン・寝室を自由に動く。ネズミやエサを食べると **太る**
- 太るほど **パンチが強く、重い物も押せる**。でも **跳べる高さが下がる**（3kg で約1m、30kg で約45cm）
- **ソファの下（20cm）や冷蔵庫の横のすき間** は細い猫しか入れない。中で太ると **詰まって** 3.5秒でアウト
- **F で毛玉を吐く** と痩せる（吐いている間は動けない）
- 棚やテーブルの物を **叩き落とすと物理で落ちて割れ、被害総額が増える**
- きゅうりに驚いて跳ねる / またたびで酔う / 放っておくと香箱座り → 寝る / E で鳴く / 天の声がツッコむ
- 100kgで破裂

## ステージ
1. 朝ごはん（カリカリを食べる・マグカップを落とす・出窓でひなたぼっこ）
2. ソファの下（4kgを超えると詰まる）
3. 重い段ボール（25kg以上で押せる。でもベッドは約26kgを超えると跳び乗れない）
4. ルンバ地獄（床はルンバだらけ。高いところのおやつを集める）
5. キッチン大荒らし（100秒で被害総額 ¥300,000）
6. ラスボス: ルンバ大魔王（おやつを吸って巨大化するルンバより太って丸のみ）

## 操作
マウス: 見回す（クリックでマウスをロック） / WASD: 移動 / Shift: 走る / スペース: ジャンプ（長押しで高く） / クリック: 猫パンチ / F・右クリック: 毛玉を吐く / E: 鳴く / R: やり直し / M: 音

## ファイル構成（`fatcat/`、ES モジュール）
- `main.js` 起動・タイトル・入力・ループ / `game.js` 猫の操作と当たり判定・食事・パンチ・詰まり・敵・目標・カメラ
- `cat.js` 猫の3Dモデル（体重で体形が変わる、シェル法の毛皮、歩き・ジャンプ・香箱座りなどの動き）
- `world.js` 実寸大のアパートと照明 / `props.js` 物理で落ちて割れる小物 / `entities.js` ネズミ・ルンバ・食べ物・きゅうり
- `stages.js` ステージ定義 / `config.js` 体重と体の寸法・ジャンプ力などの式、天の声 / `hud.js` 画面の文字 / `audio.js` 効果音 / `textures.js` テクスチャ

以前のツインスティックシューター（`scenes/`, `main.js`）は残してありますが、トップページからは使われていません。
