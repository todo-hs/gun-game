# gun-game

このプロジェクトはPhaserJSで作られたツインスティックシューターゲームです。Vampire SurvivorsとBrotatoにインスパイアされた、ローグライクサバイバルゲームです。

## 🎮 ゲームの特徴

- **ツインスティック操作**: WASDで移動、マウスで照準
- **自動射撃システム**: マウスの方向に自動で弾を発射
- **Wave制の敵**: 時間経過で敵が強化
- **経験値システム**: 敵を倒すとXPオーブをドロップ
- **レベルアップ**: 3つのランダムアップグレードから選択
- **ステータス強化**: 攻撃速度、移動速度、ダメージなど

## 🕹️ 操作方法

- **WASD**: プレイヤーの移動
- **マウス**: 照準の操作（自動射撃）
- **レベルアップ時**: 3つのアップグレードから1つを選択

## 🚀 デプロイ

このゲームはVercelで静的ホスティングされています。

### ローカルで実行

```bash
# プロジェクトをクローン
git clone https://github.com/todo-hs/gun-game.git
cd gun-game

# ブラウザでindex.htmlを開く
open index.html
```

### Vercelへのデプロイ

1. GitHubにリポジトリをプッシュ
2. Vercelでプロジェクトをインポート
3. フレームワーク設定: Other
4. ビルドコマンド: なし
5. 出力ディレクトリ: /

# 🐱 デブ猫、詰まる。 〜太るほど強い。でも穴に詰まる。100kgで破裂する。〜

トップページ（`index.html`）で遊べるメインのゲームです。コードは `fatcat/` にあります（`/fatcat/` でも同じものが開きます）。ローカルなら `python3 -m http.server` を起動して `http://localhost:8000/` を開いてください。

## ルール
- 上から見た茶トラ猫を操作する。ネズミ・魚・犬を食べると **太る**。体重がそのまま体力
- **猫パンチ**（クリック）と **飛びかかり**（長押しでお尻フリフリ → 離すとジャンプ）で狩る。空中で獲物に触れたら捕まえる。ジャンプ中は穴も飛び越えられる
- 太るほどパンチは強く、飛べる距離は短くなる。30kg以上は着地で「ドスン」と周りを踏みつぶす
- 太ると **穴や通路に入れない**。穴の中で太ると **詰まって** 3.5秒で死亡
- **SPACE / 右クリックで吐く** と痩せる。反動で吹っ飛ぶ（ゲロジェット）。毛玉は攻撃になり、落ちると魚に戻る
- 40kgを超えると **止まれない**。25kg以上なら **段ボール壁を体当たりで破壊**。10kgを超えると **薄い床が抜ける**。**100kgで破裂**
- 猫あるある: 棚の物を叩き落とすと **被害総額** が増える / **きゅうり** に驚いて勝手に大ジャンプ / **またたび** で酔っ払う / 放っておくと丸まって **寝る** / E で鳴く
- 死ぬたびに **天の声** がツッコむ

## ステージ
1. 食べると太る（チュートリアル）
2. 体重計ドア（14kg以上で開くドアのすぐ先に 7.3kg までのトンネル）
3. 床が抜ける（25kgで段ボールを壊し、10kg以下で薄い床を渡る）
4. 掃除機がくる（強制スクロール＋トンネル内の罠の魚）
5. ボス: ブル太
6. 最終試験（全部入り）
7. ラスボス: ルンバ大魔王（魚が降る中、魚を吸って巨大化するルンバより太って丸のみ。ただし100kgで破裂）

## 操作
WASD/矢印: 移動 / クリック: 猫パンチ / 長押し→離す: 飛びかかり / SPACE・右クリック: 吐く / E: 鳴く / R: 即リトライ / ESC: タイトル / M: 音のオンオフ

## ファイル構成
- `fatcat/levels.js` ステージのマップ（文字で編集できる）
- `fatcat/config.js` 体重と大きさ・速さ・パンチ・ジャンプの式、敵や棚の物のパラメータ、天の声のセリフ、効果音（ニャーも合成音）
- `fatcat/CatArt.js` 猫の描画（しっぽ・足・呼吸・寝姿を毎フレーム描く）
- `fatcat/GameScene.js` ゲーム本体 / `HudScene.js` 画面UI / `TitleScene.js` タイトル / `BootScene.js` タイルや小物のスプライト描画

以前のツインスティックシューター（`scenes/`, `main.js`）は残してありますが、トップページからは使われていません。
