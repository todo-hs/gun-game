# gun-game

このプロジェクトはPhaserJSで作られたツインスティックシューターゲームです。Vampire SurvivorsとBrotatoにインスパイアされた、ローグライクサバイバルゲームです。

## 🎮 ゲームの特徴

- **ツインスティック操作**: WASDで移動、マウスで照準
- **自動射撃システム**: マウスの方向に自動で弾を発射
- **Wave制の敵**: 時間経過で敵が強化
- **経験値システム**: 敵を倒すとXPオーブをドロップ
- **レベルアップ**: 3つのランダムアップグレードから選択
- **ステータス強化**: 攻撃速度、移動速度、ダメージなど

## 🕹️ 操作方法

- **WASD**: プレイヤーの移動
- **マウス**: 照準の操作（自動射撃）
- **レベルアップ時**: 3つのアップグレードから1つを選択

## 🚀 デプロイ

このゲームはVercelで静的ホスティングされています。

### ローカルで実行

```bash
# プロジェクトをクローン
git clone https://github.com/todo-hs/gun-game.git
cd gun-game

# ブラウザでindex.htmlを開く
open index.html
```

### Vercelへのデプロイ

1. GitHubにリポジトリをプッシュ
2. Vercelでプロジェクトをインポート
3. フレームワーク設定: Other
4. ビルドコマンド: なし
5. 出力ディレクトリ: /

# 🐱 デブ猫、町内会長になる。 〜食べ歩いて太れ。でも隙間は通れない。100kgで破裂する。〜

トップページ（`index.html`）で遊べるメインのゲームです。アニメ調（トゥーン描画）の猫になって、猫目線の町を歩き回る3Dオープンワールド（Three.js）。
ローカルなら `python3 -m http.server` を起動して `http://localhost:8000/` を開いてください（ES モジュールなのでファイル直開きでは動きません）。

## 目的
町の3匹のボス猫を倒して、神社の「町内会長の座」に座ればエンディング。ボスは体重が近くないとパンチが効かない。
- **ミケ姐さん（12kg）**: 住宅街の屋上。物置→室外機→ベランダと跳んで登る。ジャンプ力が落ちるので **18kg を超えると登れない**
- **ブチ（25kg）**: 公園の砂場。とにかく太れ
- **クロ（40kg）**: 路地裏。入口の隙間は **8kg まで**。中の残飯で太って勝ったら、内側の重い扉を **35kg 以上で** 押し開けて出る

## 町
- 商店街: 魚屋（カウンターの魚を食べるとおやじがほうきで払う。30kg あればびくともしない）/ 焼き鳥屋（焼き台は熱い）/ パン屋 / コンビニ / 大通りのトラック（はねられたら失敗。60kg あればトラックが止まる）
- 住宅街・犬のいる家（鎖の範囲に入ると噛まれる。30kg あれば犬が降参）/ 公園（ベンチのおばあちゃんに鳴くとおやつ）/ 路地裏 / 神社
- ゴミ箱を猫パンチで倒すと中身が出る。カラスは食べ物を盗むので追い払う
- 町の猫に E で鳴くとヒントをくれる。猫缶バッジ 10 個が隠れている（車の下は 6kg まで、など）
- 失敗（詰まる・破裂・トラック）しても、家（段ボール）から再開。倒したボスと集めたバッジはそのまま。進行は自動で保存

## 操作
WASD: 移動 / Shift: ダッシュ（スタミナ制。太るほど早くバテる） / マウス or 矢印キー: 見回す / スペース: ジャンプ（長押しで高く） / クリック or J: 猫パンチ / F・右クリック・K: 吐いて痩せる / E: 鳴く（話しかける） / Esc: メニュー / M: 音

マウスがなくてもキーボードだけで遊べます。

## ファイル構成（`fatcat/`、ES モジュール）
- `main.js` 起動・タイトル・入力・ループ・空と光 / `game.js` 猫の操作と当たり判定・食事・パンチ・詰まり・町の出来事・カメラ
- `town.js` 町の地形と建物（材質ごとにまとめて描画）・当たり判定・出現位置 / `toon.js` トゥーン陰影と輪郭線
- `catmodel.js` アニメ調の猫（毛色・表情・体重で体形が変わる） / `felines.js` 町の猫とボス猫
- `critters.js` ネズミ・カラス・犬・人間・トラック / `items.js` 食べ物・ゴミ箱・猫缶バッジ
- `config.js` 体重と体の寸法・ジャンプ力などの式、食べ物、ボス、天の声、セーブ / `hud.js` 画面の文字と地図 / `audio.js` 効果音

以前のツインスティックシューター（`scenes/`, `main.js`）は残してありますが、トップページからは使われていません。
